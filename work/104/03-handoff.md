## Decisions
- D1 (R1 OQ1, R2 FOR 3): continuation lines are allowed. An indented line under a closed (scalar-valued) parent, indented more than that parent's node column, is a plain continuation of its value. It gets the plain value check on its whole text. An indented line under an open parent (empty value, a value that is only a comment, or a bare `-`), or indented no more than the closed parent's column, is a structure line. It is parsed as `- ` prefixes, then an optional KEY_RE key, then a value. The node column is the column after the lead spaces and any `- ` prefixes, so p13's `- matcher: "Bash"` has column 6 (M64 pins it).
- D2 (R1 OQ2, R2 FOR 2): skip block content. A non-FLOW_KEYS structure line whose value starts with `|` or `>` must fullmatch BLOCK_RE, or it is BLOCK. The lines after it that are blank, or whose leading-space count is greater than the header line's node column, are content and skip the 104 checks (state is not updated). The 080/087 per-line checks (DOC, lead tab, VALUE_START_RE checks) still run on content first, so their documented false errors stay.
- D3 (R1 OQ3): no sibling-indent stack. Documented as not checked.
- D4 (R1 OQ4): `_field` is unchanged. `tools: # c` / `- Read` stays a `_field` false error, documented and pinned by v21.
- D5 (R1 OQ5, R2 AGAINST 3): cap = `colon index − key start > 1024`, in Python `str` characters, for every KEY_RE key at any indent. The colon index includes spaces before the colon. If I2's probe (1024 and 1025, as the first line, after `name: x`, and indented under `hooks:`) shows a different PyYAML boundary, I2 uses that boundary or a lower one (fail closed) and states it as a Deviation in 05 with the probe output.
- D6 (R2 AGAINST 2): no `pytest.importorskip("yaml")` cross-check. The test's result would depend on the environment (the RI-014 pattern).
- D7 Error texts: `VALUE = "colon in unquoted value on frontmatter line {} (item 104; quote the value)"`, `KEY_LONG = "key longer than 1024 characters on frontmatter line {} (item 104)"`, `BLOCK = "unreadable block scalar header on frontmatter line {} (item 104)"`. `n` is the test's own count (`i + 2`), not PyYAML's mark.
- D8 (R2 AGAINST 1): `name: x:` (end-of-line colon) is VALUE, failing closed. If I2's probe shows that PyYAML loads it, 05 says so and the docstring lists it under known fail-closed false errors. The same applies to `> foo` (BLOCK).
