### Exact rules
`_md_lines(text)` returns `(rows, open_at_end)`. `rows` is one `(line, state)` per line of `re.sub(r"<!--.*?-->", "", text, flags=re.S).splitlines()`, with state `out`, `mark` (an opening or closing fence line) or `in`. Outside a fence, a line is an opener if `FENCE_OPEN.fullmatch(line)` matches and not (the char is a backtick and group 2 contains a backtick). The fence's char and length (`len(m[1])`) are kept. Inside a fence, a line is the closer if it fully matches ` {0,3}C{n,}[ \t]*`, where C is the char (escaped) and n the opener's length. Every other line inside is `in`. `open_at_end` is True when a fence is open after the last line. Python 3.10 syntax only (no possessive quantifiers).

`uncommitted_steps(logs)`: return None if `_git("rev-parse", "HEAD") is None`. Run `_git("ls-tree", "-r", "--name-only", "HEAD", "--", "work/")`. A non-zero exit returns `("git ls-tree HEAD failed (item 077)", True)`. Otherwise `committed` is the set of its lines. For each `work/<ddd>/` dir (sorted) and each step 01-06 (sorted), if the file exists, `work/<ID>/<name>` is not in `committed` and `_logged(text, AGENT[s], ID)` is False, add `<ID> <name> (not in HEAD, no <agent> log line; a cut-off run? item 077)`. Return `("; ".join(entries) or "none", bool(entries))`.
