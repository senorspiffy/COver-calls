## Findings (one claim per line, each with [source URL] or UNVERIFIED)
### Tools
- T1 `Pattern.search`: "Scan through *string* looking for the first location where this regular expression produces a match". `Pattern.fullmatch`: "If the whole *string* matches this regular expression, return a corresponding Match. Return None if the string does not match". [https://docs.python.org/3/library/re.html]
- T2 The same page: `re.search()` "checks for a match anywhere in the string"; `re.fullmatch()` "checks for entire string to be a match". [https://docs.python.org/3/library/re.html]
- T3 `print(*objects, sep=' ', end='\n', file=None, flush=False)`: each print ends with `end`, default `'\n'`, so each `print` in check_handoff.py is one stdout line. [https://docs.python.org/3/library/functions.html]
- T4 Lists "are compared lexicographically ... to compare equal, every element must compare equal and the two sequences must be of the same type and have the same length." So `out.splitlines() == [..]` fails on an extra, missing or reordered line. A membership loop (`_ok3` today) does not. [https://docs.python.org/3/library/stdtypes.html]
- T5 `contextlib.redirect_stdout`: "Context manager for temporarily redirecting sys.stdout to another file object." This is how `check_all` collects `main`'s output (check_handoff.py L160-163). [https://docs.python.org/3/library/contextlib.html]
- T6 pytest monkeypatch: "Use monkeypatch.setattr to patch the function or property with your desired testing behavior." "All modifications will be undone after the requesting test function or fixture has finished." [https://docs.pytest.org/en/stable/how-to/monkeypatch.html]
- T7 pytest capsys: "The return value of readouterr() is a namedtuple with two attributes, out and err". In sys mode "Only writes to Python files sys.stdout and sys.stderr will be captured". That is enough for an in-process `check_all` call, which writes only through `print`. [https://docs.pytest.org/en/stable/how-to/capture-stdout-stderr.html]
