## Extra research (with sources)
1. Rename detection is on by default in porcelain diff and off in plumbing. git-config `diff.renames`: "Defaults to true. Note that this affects only *git diff* Porcelain like git-diff[1] and git-log[1], and not lower level commands" (https://git-scm.com/docs/diff-config). git-diff `--no-renames`: "Turn off rename detection, even when the configuration file gives the default to do so" (https://git-scm.com/docs/git-diff). → change 3: `diff-tree` (plumbing) plus `--no-renames` explicitly.
2. A shallow fixture needs a `file://` URL. git-clone: a local path "implies `--local`", which "clones the repository by making a copy of `HEAD` and everything under objects and refs directories". With `file:///path`, "this flag is ignored" (https://git-scm.com/docs/git-clone, `--local` and GIT URLS). So fixture (d) must run `git clone --depth 1 file://<repo>`. With a plain path git copies the whole history and the clone is not shallow.
3. Non-ASCII paths are quoted unless `-z` is used (git-diff `-z`: "pathnames with 'unusual' characters are quoted as explained for … `core.quotePath`", same URL). Every CODE_PATH and every `work/<ID>/0N-*.md` name in this repo is ASCII, so prefix matching is safe without `-z`. This is listed as a known gap rather than handled.
4. The 001 rule text needs no change for map step 7. 001 § Correction "Step 3, person's decision 2026-11-03 (040)" says "estimated date = last report + `earnings_gap_days`". A `last_earnings` that is not before the scan date is not a report that has happened on that date, so the guard does what the person's rule already says. The wording changes only in the code docs (tickers.py docstring, missing.py row).
