First, A1 runs the Inbox step (a1-auditor job B, item 069) and puts its section at the top of the report. Use the a1-auditor agent in daily-review mode for today's date. If `git rev-parse --is-shallow-repository` prints true, run `git fetch --unshallow`, then test again. If it is still true, report UNTRACKED CHANGE, RESEARCH CODE, REAL-DATA FIELD, LOG TIME, MAIN AHEAD, OPEN BRANCHES and RULE NOT SEEN as 'not checked', never 'none' (items 079, 084, 090). If `git config --get-all remote.origin.fetch` has no `+refs/heads/*:refs/remotes/origin/*` line (with or without the `+`) or has a line starting with `^`, run `git remote set-branches origin '*' && git fetch origin`, then test again; until then report OPEN BRANCHES, IN PR, RULES BRANCH and ID CLASH as 'not checked', never 'none', and take no ID from `--next-id` (item 094). It runs `python3 scripts/check_pipeline.py` and `python3 scripts/check_handoff.py --all`, and puts the STUCK items (request.md only, 1+ day old) at the top of the report with a question to the person: which to run. Then list any new BUG, EFFICIENCY and IDEA (inbox) work items it opened, and run each through /run-item the same day (IDEA items from the inbox run with the day's BUG and EFFICIENCY items).
